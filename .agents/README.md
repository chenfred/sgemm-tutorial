# Agent 协作目录

`.agents/` 只保存 agent 协作所需的内部资料，避免把计划、交接和上下文记忆散落到项目根目录。

- `memories/`：跨会话保留的高密度项目状态、关键决策和经验教训。
- 后续如需计划、交接或短期分析，分别放在 `.agents/plans/`、`.agents/handoffs/` 或 `.agents/scratch/`；没有实际内容时不预建空目录。
- 面向学习者长期阅读的正式材料仍放在 `docs/`，源代码和构建脚本仍按仓库既有结构存放。

根目录 `AGENTS.md` 是 Codex 默认自动发现的仓库指引入口，因此当前不属于可随意移动的普通协作资料。
