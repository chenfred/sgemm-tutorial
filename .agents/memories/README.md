# 项目记忆索引

本目录保存“未来 agent 不应依赖聊天上下文才能知道”的信息，不保存原始对话、命令长输出或逐轮流水账。

## 维护规则

在以下时机更新本目录：

1. 用户明确验收一轮任务后；
2. 上下文即将压缩前；
3. 出现重要状态变化、关键结论或可复用的失败经验时。

维护时直接修订对应主题文件。当前事实变化后删除旧值；只有仍能防止重复踩坑的失败尝试才保留，并明确标记为历史。能由源码或正式文档直接、低成本恢复的细节不重复抄录。
